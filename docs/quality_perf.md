## Что входит в уровни качества

| | Низкое | Среднее | Высокое |
| --- | --- | --- | --- |
| Разрешение рендера | 75 % | 100 % | до 200 % (по экрану) |
| Тени | нет | 1024 | 2048 |
| Сглаживание и свечение | нет | MSAA ×2, bloom | MSAA ×4, bloom |
| Стекло | простое прозрачное | простое прозрачное | с преломлением |
| Отражения окружения | только металл, стекло, камни | везде | везде |
| Контровой свет, пыль в луче | нет | есть | есть |

При первом запуске игра сама выбирает качество: рисует несколько кадров на «высоком», затем на «среднем», и берёт самое красивое, где кадр укладывается в 9 мс. На Intel UHD выбирается «низкое», на RTX 4060 — «высокое».
