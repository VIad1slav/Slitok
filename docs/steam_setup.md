# Настройка Steamworks для Golden Grab

Что надо сделать в кабинете Steamworks и в проекте, чтобы игра заработала со Steam. Всё, что уже сделано в коде,
помечено «готово».

## 1. App ID

- Сейчас в `electron/config.js` стоит **тестовый App ID 480** (Spacewar) — и для разработки, и для сборки.
- После регистрации игры впишите настоящий номер в поле `steamAppId` и пересоберите (`npm run build:win`).
- Когда номер настоящий, собранная игра, запущенная не из Steam, сама перезапустится через Steam
  (`restartAppIfNecessary`). С номером 480 этого не происходит.
- `steam_appid.txt` создаётся только при запуске из исходников (`npm run desktop`) и в сборку не попадает.

## 2. Облачные сохранения (Steam Auto-Cloud)

Код для облака не нужен: Steam сам синхронизирует папку.

| Поле в Steamworks (Steam Cloud → Auto-Cloud) | Значение для Windows |
| --- | --- |
| Root | `WinAppDataRoaming` |
| Subdirectory | `Golden Grab/saves` |
| Pattern | `*.json` |
| OS | Windows |
| Recursive | нет |

- Полный путь на диске: `%APPDATA%\Golden Grab\saves\` (например `C:\Users\<имя>\AppData\Roaming\Golden Grab\saves\`).
- Файлы: `save.json` — прогресс (рекорды, рука, достижения), `settings.json` — настройки.
  Если не хотите, чтобы настройки графики переезжали между компьютерами, задайте Pattern `save.json`.
- Запасные копии `*.json.bak` и отложенные повреждённые файлы `*.corrupt-*` под маску `*.json` не попадают.
- Для Linux / Steam Deck (если будет сборка): Root `LinuxXdgConfigHome`, Subdirectory `Golden Grab/saves`.
  Добавьте её как «Root Override» к той же записи, чтобы облако было общим.
- Квота: файлы занимают несколько килобайт; хватит 1 МБ и 10 файлов.

## 3. Достижения

- Таблица с API-именами, названиями и описаниями EN/RU — `docs/steam_achievements.md` (18 штук).
- Иконки 256×256 — `docs/steam/achievements/` (`<API Name>.png` и `<API Name>_locked.png`).
- В Steamworks: Stats & Achievements → New Achievement → вписать API Name буква в букву, загрузить обе иконки,
  добавить русскую локализацию названия и описания. Статистика (Stats) не нужна.
- Не забудьте нажать «Publish» — до публикации изменений достижения игре не видны.

## 4. Библиотека

Игра работает со Steam через **steamworks.js 0.4.0** (готово, `electron/steam.js`).

- Почему она: готовые бинарные файлы для Windows, Linux и macOS вместе с библиотекой Steam внутри пакета
  (не нужно отдельно скачивать Steamworks SDK), достижения и оверлей поддерживаются, работает в главном
  процессе Electron. Это библиотека на N-API — её двоичный интерфейс не зависит от версии Electron,
  с Electron 45 она загрузилась и подключилась к Steam (проверено 2026-11-13 с App ID 480).
- Риск: последний выпуск — август 2024 года. Запасной вариант, если она перестанет работать с новым клиентом
  Steam: `steamworks-ffi-node` (обновляется, но требует вручную положить файлы из Steamworks SDK).
  Менять придётся один файл — `electron/steam.js`.

## 5. Если Steam не запущен

Игра запускается и работает как обычно, ошибок на экране нет (проверяет `node tools/test/desktop.mjs`).
Достижения запоминаются в `save.json` и уходят в Steam при следующем запуске со Steam.

## 6. Оверлей Steam (Shift+Tab)

- Включён настройкой `steamOverlay: true` в `electron/config.js`; ключи запуска для него выставляются,
  только если Steam найден.
- **Вживую не проверен.** Оверлей появляется только у игры, запущенной из клиента Steam, а для этого нужен
  настоящий App ID и загруженная сборка. С App ID 480 из исходников проверено лишь, что с включённой настройкой
  игра запускается, проходит уровень и захватывает мышь.
- В Electron оверлей известен нестабильностью (не рисуется, пока кадр не обновился; иногда чёрный экран).
  Если после загрузки сборки он мешает — поставьте `steamOverlay: false`. На игру, достижения и облако это не влияет.
- Когда оверлей открыт, окно теряет фокус и игра сама встаёт на паузу — это задумано.

## 7. Что проверить руками после загрузки первой сборки

1. Запуск из библиотеки Steam: игра открывается, Shift+Tab показывает оверлей.
2. Пройти «Разминку» быстрее 10 секунд — должно выпасть достижение «Хватай и беги».
3. Поменять перчатку, выйти, удалить папку `%APPDATA%\Golden Grab\saves`, запустить снова — Steam должен вернуть
   сохранение из облака.
