# Golden Grab

Игра от первого лица: просунь руку в стеклянную коробку, возьми золотой слиток и вынеси его в «сейф», не разбив стекло и не задев ловушки. Чистый HTML + ES-модули, без сборщика. Библиотеки three@0.160.0 и cannon-es@0.20.0 лежат в `vendor/` — интернет игре не нужен. Языки — английский и русский. Выпускается в Steam как настольное приложение для Windows (Electron); в браузере работает из тех же файлов.

## Запуск

```bash
npx serve . -l 5173
```

или

```bash
python -m http.server 5173
```

Затем открыть http://localhost:5173. Открывать `index.html` двойным щелчком нельзя: модули и текстуры грузятся только с сервера.

Отладочный доступ из консоли (`__gg`) есть только в режиме разработки: в браузере — по адресу http://localhost:5173/?dev=1.

### Настольное приложение

```bash
npm install
```

```bash
npm run desktop
```

Открывает игру в окне Electron в режиме разработки (DevTools по F12, `__gg` доступен). `npm run desktop:release` — то же, но как у игроков: без DevTools и отладки.

```bash
npm run build:win
```

Собирает папку `dist/win-unpacked` (Windows x64, 325 МБ, внутри `Golden Grab.exe`) — её и загружают в Steam. `npm run build:linux` — сборка для Linux / Steam Deck (собирается, но не проверялась).

- Полный экран по умолчанию; Alt+Enter или F11 — в окно и обратно.
- Сохранение и настройки: `%APPDATA%\Golden Grab\saves\save.json` и `settings.json`. Повреждённый файл не роняет игру: берётся копия `.bak`.
- Steam: достижения и оверлей через steamworks.js; без запущенного Steam игра работает как обычно. App ID — в `electron/config.js` (сейчас тестовый 480).
- Что настроить в Steamworks — `docs/steam_setup.md`; достижения — `docs/steam_achievements.md`; тексты и скриншоты для страницы — `docs/steam_page.md`.

### После изменения ассетов или библиотек

| Что изменилось | Что запустить |
| --- | --- |
| Пересобраны текстуры в Blender | `npm run textures` — заново делает WebP из PNG |
| Обновлены three или cannon-es в `package.json` | `npm install`, затем `npm run vendor` |
| Добавлен или изменён текст для игрока | вписать в оба словаря `src/i18n/`, затем `npm run i18n` |
| Изменены достижения | `node tools/steam/achievements_doc.mjs` и `node tools/steam/achievement_icons.mjs` |

## Управление

| Клавиша | Действие |
| --- | --- |
| Мышь | двигать кисть влево-вправо и вверх-вниз |
| Колесо или W / S | вперёд и назад (вглубь коробки) |
| ЛКМ (держать) | сжать пальцы; отпустить — разжать |
| ПКМ + мышь | повернуть кисть (влево-вправо) и наклонить её (вверх-вниз) |
| Q / E | скрутить запястье — поставить кисть ребром |
| C | вид сбоку, 3 раза за уровень |
| R | уровень заново |
| Esc | пауза |

Когда слиток можно схватить, он слегка подсвечивается, а внизу экрана появляется «ЛКМ — схватить».

Каждый уровень начинается в одной и той же позе руки (`HAND_START` в `src/config.js`): перед игроком, пальцы вперёд и вниз. Повернуть и наклонить руку под отверстие — часть задачи.

## Кампания

Игра делится на ограбления; уровни ограбления открываются, когда набрано нужное число звёзд (порог — `unlockStars` в `src/heists.js`). Готовы все 40 уровней: 5 ограблений по 8.

| Ограбление | Открывается | Уровни |
| --- | --- | --- |
| Ломбард | сразу | Разминка, Заход сбоку, Узкая щель, Ловушка для обезьян, Нажимная плита, Плита в глубине, Горячий слиток, Экзамен ломбарда |
| Музей | 12 звёзд | Ваза, Лазеры, Ночной сторож, Корона, Корона ребром, Ваза под лучами, Под присмотром, Зал короны |
| Банк | 26 звёзд | Три слитка, Барьер, Заслонка, Подмена, Два окна, Монеты, Смена караула, Хранилище |
| Казино | 43 звезды | Фишки, Скользкий тип, Перебои со светом, Карусель, Кости, Бриллиант, Рулетка в темноте, Джекпот |
| Сейф босса | 62 звезды | Приёмная, Сигнализация, Тёплый приём, Коллекция, Весы босса, Карусель с заслонкой, Последний рубеж, Сейф босса |

Механики:

- **Отверстия** сверху, сбоку и спереди; узкая щель в крышке, вдоль которой надо повернуть кисть (ПКМ + мышь).
- **Ловушка для обезьян** — слиток лежит поперёк и в отверстие не проходит; его надо развернуть торцом (подтолкнуть пальцами или перехватывать с поворотом кисти).
- **Нажимная плита** — резкий подъём включает сирену и отсчёт 3 секунды; плавный подъём обманывает датчик.
- **Горячий слиток** — держать можно не дольше 2–3 секунд.
- **Лазеры** — постоянные и мигающие лучи; задевать рукой нельзя.
- **Камера наблюдения** — цикл «не смотрит → предупреждение (писк, жёлтая лампочка) → смотрит (красный свет)». Пока смотрит, рука должна стоять: движение заполняет полоску «замечен», полная полоска — провал.
- **Ваза** — хрупкая: удар быстрее 0,7 м/с оставляет трещину, вторая трещина или удар быстрее 1,3 м/с разбивают её.
- **Корона** — широкая и низкая: в узкую высокую щель проходит только ребром (Q / E ставят кисть ребром).
- **Несколько предметов** на уровне: рука держит один, донесённый в «сейф» засчитывается и исчезает, счётчик «Добыча 1 / 3».
- **Внутренние перегородки** (`box.inner` в данных уровня): низкий барьер, через который руку проносят сверху, наклонив кисть (ПКМ + мышь), и стенка с окном, смещённым относительно наружного отверстия, — руку ведут под углом по прямой через оба.
- **Заслонка** — стальная пластина на отверстии: открыта → предупреждение (жёлтая лампа, щелчки) → закрыта. Руку она не давит: доезжает и останавливается, но если упирается дольше 0,3 секунды — тревога с отсчётом 3 секунды.
- **Весы и груз** — вес на весах не должен упасть: сначала на весы кладут груз со стола, потом снимают слиток. Полоска «вес» с отметкой порога — справа вверху.
- **Стопки монет** — мелкая добыча.
- **Скользкий слиток** и хрупкое стекло; **карусель** с лимитом времени — на ней могут ехать слиток, кубики, фишки.
- **Перебои со светом** — свет дрожит (предупреждение) и гаснет на пару секунд. Темнота уровень не проваливает, она прячет коробку: видны только светящиеся торцы стекла, круг «сейфа», лазеры и индикаторы ловушек — темноту можно переждать. В меню есть переключатель «Мигание света: включено / плавное» для тех, кому вспышки неприятны.
- **Бриллиант** — крошечный и скользкий: выскальзывает на скорости 0,45 м/с (слиток — 1,85) и выпадает от удара руки о стекло. Справа вверху полоска «хват».
- **Фишки и кубики** — мелкая добыча, по несколько штук на уровне.
- **Большой слиток** — 26 см и 6 кг: выскальзывает уже на скорости 0,9 м/с, нужны отверстия крупнее.
- **Пятно камеры** — вариант камеры наблюдения: она смотрит всегда, но только в красный круг, который ползёт по столу. Пока кисть в круге, двигаться нельзя.
- **Несколько отверстий в одной коробке** — у каждого предмета своё (поле `via`), как на уровне «Коллекция».
- **Многоэтапный уровень** («Сейф босса», три этапа): добыча этапа в сейфе — начинается следующий, время и касания общие. «Ещё раз» после провала возвращает на текущий этап, время продолжает идти.

У каждого ограбления своя обстановка (свет, оттенки, стол, набор предметов) — поле `theme` в `src/heists.js`. Косметика руки открывается по сумме звёзд (`src/cosmetics.js`): перчатки — красная (10), белая (22), зелёная (62), золотая (90); украшения поверх любой руки — золотое кольцо (34) и часы (48).

Где что лежит (всё — данные, без кода):

- `src/levels.js` — уровни. Рекорды хранятся по `id` уровня, поэтому `id` менять нельзя; порядок показа задаёт `src/heists.js`.
- `src/heists.js` — ограбления: название, порог звёзд, список `id` уровней по порядку.
- `src/loot-types.js` — типы добычи: форма, масса, сферы для проверки «кулак пролезает», модель. На уровне может быть несколько предметов (`loot: [...]` вместо `bar: {...}`); донесённый в «сейф» предмет засчитывается и исчезает.
- `src/cosmetics.js` — варианты руки и порог звёзд для каждого.
- `src/i18n/en.js`, `src/i18n/ru.js` — все тексты для игрока (названия и подсказки уровней, меню, причины провала). В остальном коде текста нет, только ключи: `t('menu.play')`.

Прогресс и настройки хранятся раздельно (`src/save.js`): в браузере — в localStorage, в приложении — в файлах JSON. Сохранения любого старого вида читаются без потерь.

## Настройки и качество графики

Экран «Настройки» открывается из главного меню и из паузы: язык, качество графики, полный экран, предел кадров, счётчик кадров, чувствительность мыши, инверсия вперёд-назад, громкость эффектов и фона, мигание света.

| | Низкое | Среднее | Высокое |
| --- | --- | --- | --- |
| Разрешение рендера | 75 % | 100 % | по экрану |
| Тени | нет | 1024 | 2048 |
| Сглаживание и свечение | нет | есть | есть |
| Стекло | простое | простое | с преломлением |
| Intel UHD, 1080p | 74–115 кадров/с | 21–25 | 11–12 |
| RTX 4060, 1080p | 450+ | 140–360 | 140–220 |

При первом запуске качество подбирается само по скорости видеокарты. Уровни качества — `QUALITY` в `src/scene.js`; замеры по всем уровням — `docs/quality_perf.md` (`node tools/test/quality.mjs`).

## Настройка ощущения руки

Все параметры — в `src/config.js`, блок `HAND`:

| Параметр | Что делает |
| --- | --- |
| `stiffness` | жёсткость пружины «цель → кисть»: больше — рука резче и послушнее |
| `damping` | демпфирование: меньше — рука сильнее раскачивается и проскакивает цель (критическое ≈ 2·√stiffness) |
| `maxSpeed` | предел скорости кисти, м/с |
| `leash` | насколько цель может убежать от упёршейся в стекло кисти (больше — сильнее «пружинит» после упора) |
| `mouseSens`, `wheelStep`, `keySpeed` | чувствительность мыши, шаг колеса, скорость W/S |
| `rotSens`, `yawSpeed`, `rotFollow`, `rotMaxRate` | чувствительность и инерция вращения запястья |
| `gripCloseRate`, `gripOpenRate` | скорость сжатия и разжатия пальцев |
| `grabDistance`, `grabThreshold` | насколько прощающий захват |
| `slipSpeed`, `slipTime`, `slipDrift` | когда слиток выскальзывает (на уровне можно переопределить `grip.slipSpeed`) |
| `lockMaxForce` | сила constraint’а, держащего слиток |

Рядом: `GLASS` (порог удара `hitSpeed`, прочность `health`), `PHYS` (шаг 1/120, трение), `HAND_GEOM` (сферы-коллайдеры руки), `WORLD` (камера, плечо, стол). Свет и постобработка — `LIGHT` в `src/scene.js`.

## Ассеты из Blender

Модели и текстуры строятся скриптами `bpy` (проверено на Blender 5.3.0):

```bash
blender --background --python tools/blender/build_all.py
```

Если `blender` не в PATH, укажите полный путь к исполняемому файлу. Отдельные этапы: `build_models.py` (GLB + превью моделей) и `bake_textures.py` (запекание Cycles + превью; можно `-- only=gold,skin`). Параметры коробок берутся из `src/levels.js` через `node tools/export_levels.mjs`, поэтому после изменения размеров коробки или отверстия ассеты надо пересобрать — иначе игра покажет старое стекло при новой физике.

- `assets/models/` — hand.glb (скелет: forearm, wrist, thumb/index/middle/ring/pinky _01.._03), gold_bar.glb, vase.glb, crown.glb, coins.glb, weight.glb, chips.glb, dice.glb, diamond.glb, ring.glb и watch.glb (украшения в координатах руки, игра вешает их на кости), camera.glb (cam_base и cam_head), shutter.glb (единичная пластина, растягивается под отверстие), glass_box.glb (стенки `L<id уровня>_<стенка>` и перегородки `L<id>_inner<номер>`; у этапов финала id вида `40s1`), table.glb, pedestal.glb, room.glb (стены и лампа), set_pawnshop.glb, set_museum.glb, set_bank.glb, set_casino.glb и set_boss.glb (обстановка ограблений).
- `assets/textures/` — наборы `*_albedo.png`, `*_normal.png` (OpenGL), `*_orm.png` (R = AO, G = roughness, B = metalness) для gold, skin, glove, vase, crown, chips, dice и окружения (в том числе felt_green — сукно); `glove_light_albedo.png` — светлая перчатка под подкраску; `glass_smudges.png`, `glass_cracks_1..3.png`.
- `tools/blender/previews/` — превью для проверки глазами.

Если GLB или PNG не загрузился, игра подставляет запасную геометрию из примитивов и процедурную текстуру (Canvas 2D) и пишет об этом в консоль.

## Проверки

```bash
node tools/check_levels.mjs
```

Геометрия: отверстие пропускает руку и кулак со слитком, слиток достижим, ловушка для обезьян не пускает слиток поперёк.

```bash
npm install
```

```bash
node tools/test/play.mjs --shots
```

Запускает игру в установленном Chrome или Edge (Playwright) и проверяет: ассеты загружены и консоль без ошибок; игра работает с заблокированной сетью; старое сохранение читается без потерь; оба языка, текст не вылезает за кнопки; экран загрузки; автопилот проходит все уровни кампании, и время не ушло от эталона больше чем на 10 %; рука различима на фоне во всех обстановках и в темноте; настройки и достижения; рука не проходит сквозь стекло, стекло бьётся; нагрузка на отрисовку по уровням. Скриншоты — в `docs/screens/`.

```bash
node tools/check_i18n.mjs
```

Локализация: в строках кода нет русского текста (он весь в словарях), ключи английского и русского словарей совпадают.

```bash
node tools/test/desktop.mjs
```

Настольная версия: открывает настоящее окно игры (на несколько секунд оно появится на экране) в режиме разработки и в режиме для игроков. Проверяет изоляцию окна, полный экран, захват мыши, паузу при потере фокуса, файлы сохранений (запись, перезапуск, повреждённый файл, перенос из localStorage), запуск без Steam, запрет DevTools. С ключом `--exe "dist/win-unpacked/Golden Grab.exe"` проверяет собранное приложение и проходит уровень 1 настоящим вводом мыши. Если в это время за компьютером работают, Windows может не отдать окну фокус — тогда проверки захвата мыши пропускаются с пометкой «пропуск».

Симуляция детерминирована: время автопилота повторяется до сотой секунды. Если оно изменилось, значит изменилась физика, уровень или сценарий автопилота. Эталон — таблица `BASELINE` в начале `tools/test/play.mjs`.

В консоли браузера (адрес с `?dev=1`): `__gg.runAuto(3)` — посмотреть, как автопилот проходит уровень с `id` 3.

Для отладки: `node tools/test/eval.mjs script.js [shot.png]` запускает игру, выполняет в ней JavaScript из файла и печатает результат.
