# Golden Grab

Игра от первого лица: просунь руку в стеклянную коробку, возьми золотой слиток и вынеси его в «сейф», не разбив стекло и не задев ловушки. Чистый HTML + ES-модули, без сборщика. three@0.160.0 и cannon-es@0.20.0 подключаются через importmap с cdn.jsdelivr.net (нужен интернет при первом запуске).

## Запуск

```bash
npx serve . -l 5173
```

или

```bash
python -m http.server 5173
```

Затем открыть http://localhost:5173. Открывать `index.html` двойным щелчком нельзя: модули и текстуры грузятся только с сервера.

## Управление

| Клавиша | Действие |
| --- | --- |
| Мышь | двигать кисть влево-вправо и вверх-вниз |
| Колесо или W / S | вперёд и назад (вглубь коробки) |
| ЛКМ (держать) | сжать пальцы; отпустить — разжать |
| ПКМ + мышь | наклон (вверх-вниз) и вращение (влево-вправо) запястья |
| Q / E | поворот кисти влево-вправо |
| C | вид сбоку, 3 раза за уровень |
| R | уровень заново |
| Esc | пауза |

Когда слиток можно схватить, он слегка подсвечивается, а внизу экрана появляется «ЛКМ — схватить».

## Кампания

Игра делится на ограбления; уровни ограбления открываются, когда набрано нужное число звёзд (порог — `unlockStars` в `src/heists.js`). Сейчас готовы 32 уровня из 40.

| Ограбление | Открывается | Уровни |
| --- | --- | --- |
| Ломбард | сразу | Разминка, Заход сбоку, Узкая щель, Ловушка для обезьян, Нажимная плита, Плита в глубине, Горячий слиток, Экзамен ломбарда |
| Музей | 12 звёзд | Ваза, Лазеры, Ночной сторож, Корона, Корона ребром, Ваза под лучами, Под присмотром, Зал короны |
| Банк | 26 звёзд | Три слитка, Барьер, Заслонка, Подмена, Два окна, Монеты, Смена караула, Хранилище |
| Казино | 43 звезды | Фишки, Скользкий тип, Перебои со светом, Карусель, Кости, Бриллиант, Рулетка в темноте, Джекпот |
| Сейф босса | 62 звезды | пока пусто |

Механики:

- **Отверстия** сверху, сбоку и спереди; узкая щель в крышке, вдоль которой надо повернуть кисть (Q / E).
- **Ловушка для обезьян** — слиток лежит поперёк и в отверстие не проходит; его надо развернуть торцом (подтолкнуть пальцами или перехватывать с поворотом кисти).
- **Нажимная плита** — резкий подъём включает сирену и отсчёт 3 секунды; плавный подъём обманывает датчик.
- **Горячий слиток** — держать можно не дольше 2–3 секунд.
- **Лазеры** — постоянные и мигающие лучи; задевать рукой нельзя.
- **Камера наблюдения** — цикл «не смотрит → предупреждение (писк, жёлтая лампочка) → смотрит (красный свет)». Пока смотрит, рука должна стоять: движение заполняет полоску «замечен», полная полоска — провал.
- **Ваза** — хрупкая: удар быстрее 0,7 м/с оставляет трещину, вторая трещина или удар быстрее 1,3 м/с разбивают её.
- **Корона** — широкая и низкая: в узкую высокую щель проходит только ребром (ПКМ + мышь поворачивает кисть).
- **Несколько предметов** на уровне: рука держит один, донесённый в «сейф» засчитывается и исчезает, счётчик «Добыча 1 / 3».
- **Внутренние перегородки** (`box.inner` в данных уровня): низкий барьер, через который руку проносят сверху, наклонив кисть (ПКМ + мышь), и стенка с окном, смещённым относительно наружного отверстия, — руку ведут под углом по прямой через оба.
- **Заслонка** — стальная пластина на отверстии: открыта → предупреждение (жёлтая лампа, щелчки) → закрыта. Руку она не давит: доезжает и останавливается, но если упирается дольше 0,3 секунды — тревога с отсчётом 3 секунды.
- **Весы и груз** — вес на весах не должен упасть: сначала на весы кладут груз со стола, потом снимают слиток. Полоска «вес» с отметкой порога — справа вверху.
- **Стопки монет** — мелкая добыча.
- **Скользкий слиток** и хрупкое стекло; **карусель** с лимитом времени — на ней могут ехать слиток, кубики, фишки.
- **Перебои со светом** — свет дрожит (предупреждение) и гаснет на пару секунд. Темнота уровень не проваливает, она прячет коробку: видны торцы стекла, круг «сейфа», лазеры и то, что освещает фонарик на запястье. В меню есть переключатель «Мигание света: включено / плавное» для тех, кому вспышки неприятны.
- **Бриллиант** — крошечный и скользкий: выскальзывает на скорости 0,45 м/с (слиток — 1,85) и выпадает от удара руки о стекло. Справа вверху полоска «хват».
- **Фишки и кубики** — мелкая добыча, по несколько штук на уровне.

У каждого ограбления своя обстановка (свет, оттенки, стол, набор предметов) — поле `theme` в `src/heists.js`. Косметика руки открывается по сумме звёзд (`src/cosmetics.js`): перчатки — красная (10), белая (22), зелёная (62); украшения поверх любой руки — золотое кольцо (34) и часы (48).

Где что лежит (всё — данные, без кода):

- `src/levels.js` — уровни. Рекорды хранятся по `id` уровня, поэтому `id` менять нельзя; порядок показа задаёт `src/heists.js`.
- `src/heists.js` — ограбления: название, порог звёзд, список `id` уровней по порядку.
- `src/loot-types.js` — типы добычи: форма, масса, сферы для проверки «кулак пролезает», модель. На уровне может быть несколько предметов (`loot: [...]` вместо `bar: {...}`); донесённый в «сейф» предмет засчитывается и исчезает.
- `src/cosmetics.js` — варианты руки и порог звёзд для каждого.
- `src/strings.js` — новые тексты интерфейса в одном месте (для будущего перевода).

Лучшие результаты хранятся в localStorage; сохранения старого вида читаются без потерь.

## Настройка ощущения руки

Все параметры — в `src/config.js`, блок `HAND`:

| Параметр | Что делает |
| --- | --- |
| `stiffness` | жёсткость пружины «цель → кисть»: больше — рука резче и послушнее |
| `damping` | демпфирование: меньше — рука сильнее раскачивается и проскакивает цель (критическое ≈ 2·√stiffness) |
| `maxSpeed` | предел скорости кисти, м/с |
| `leash` | насколько цель может убежать от упёршейся в стекло кисти (больше — сильнее «пружинит» после упора) |
| `mouseSens`, `wheelStep`, `keySpeed` | чувствительность мыши, шаг колеса, скорость W/S |
| `rotSens`, `yawSpeed`, `rotFollow`, `rotMaxRate` | чувствительность и инерция вращения запястья |
| `gripCloseRate`, `gripOpenRate` | скорость сжатия и разжатия пальцев |
| `grabDistance`, `grabThreshold` | насколько прощающий захват |
| `slipSpeed`, `slipTime`, `slipDrift` | когда слиток выскальзывает (на уровне можно переопределить `grip.slipSpeed`) |
| `lockMaxForce` | сила constraint’а, держащего слиток |

Рядом: `GLASS` (порог удара `hitSpeed`, прочность `health`), `PHYS` (шаг 1/120, трение), `HAND_GEOM` (сферы-коллайдеры руки), `WORLD` (камера, плечо, стол). Свет и постобработка — `LIGHT` в `src/scene.js`.

## Ассеты из Blender

Модели и текстуры строятся скриптами `bpy` (проверено на Blender 5.3.0):

```bash
blender --background --python tools/blender/build_all.py
```

Если `blender` не в PATH, укажите полный путь к исполняемому файлу. Отдельные этапы: `build_models.py` (GLB + превью моделей) и `bake_textures.py` (запекание Cycles + превью; можно `-- only=gold,skin`). Параметры коробок берутся из `src/levels.js` через `node tools/export_levels.mjs`, поэтому после изменения размеров коробки или отверстия ассеты надо пересобрать — иначе игра покажет старое стекло при новой физике.

- `assets/models/` — hand.glb (скелет: forearm, wrist, thumb/index/middle/ring/pinky _01.._03), gold_bar.glb, vase.glb, crown.glb, coins.glb, weight.glb, chips.glb, dice.glb, diamond.glb, ring.glb и watch.glb (украшения в координатах руки, игра вешает их на кости), camera.glb (cam_base и cam_head), shutter.glb (единичная пластина, растягивается под отверстие), glass_box.glb (стенки `L<id уровня>_<стенка>` и перегородки `L<id>_inner<номер>`), table.glb, pedestal.glb, room.glb (стены и лампа), set_bank.glb, set_museum.glb и set_casino.glb (обстановка ограблений).
- `assets/textures/` — наборы `*_albedo.png`, `*_normal.png` (OpenGL), `*_orm.png` (R = AO, G = roughness, B = metalness) для gold, skin, glove, vase, crown, chips, dice и окружения (в том числе felt_green — сукно); `glove_light_albedo.png` — светлая перчатка под подкраску; `glass_smudges.png`, `glass_cracks_1..3.png`.
- `tools/blender/previews/` — превью для проверки глазами.

Если GLB или PNG не загрузился, игра подставляет запасную геометрию из примитивов и процедурную текстуру (Canvas 2D) и пишет об этом в консоль.

## Проверки

```bash
node tools/check_levels.mjs
```

Геометрия: отверстие пропускает руку и кулак со слитком, слиток достижим, ловушка для обезьян не пускает слиток поперёк.

```bash
npm install
```

```bash
node tools/test/play.mjs --shots
```

Запускает игру в установленном Chrome или Edge (Playwright) и проверяет: ассеты загружены и консоль без ошибок; старое сохранение читается без потерь; автопилот проходит все уровни кампании, и время не ушло от эталона больше чем на 10 %; уровень с несколькими предметами и предметы другой формы; рука не проходит сквозь стекло, стекло бьётся; нагрузка на отрисовку по уровням. Скриншоты — в `docs/screens/`.

Симуляция детерминирована: время автопилота повторяется до сотой секунды. Если оно изменилось, значит изменилась физика, уровень или сценарий автопилота. Эталон — таблица `BASELINE` в начале `tools/test/play.mjs`.

В консоли браузера: `__gg.runAuto(3)` — посмотреть, как автопилот проходит уровень с `id` 3.

Для отладки: `node tools/test/eval.mjs script.js [shot.png]` запускает игру, выполняет в ней JavaScript из файла и печатает результат.
